Демонстрационный CSV содержит сокращённый набор колонок. Неделя ISO добавлена при объединении частей отчёта за октябрь. Внутри недели № идентифицирует строку единственного модельного отчёта, Srid связывает операции по покупке. В клиентских данных ключ строки должен включать номер исходного отчёта. Дата у хранения означает дату начисления. Расход берётся по строке услуги. В модели сумма к перечислению за товар уже включает удержание комиссии и эквайринга. Показатель «удержано из цены» получен разностью двух сумм и именно в этой модели состоит только из этих двух статей. Для фактической сверки состав разницы проверяют отдельно с учётом скидок, возмещений и корректировок. Условно все возвращённые экземпляры годны к перепродаже. Хранение вычитается один раз на уровне магазина. Налоги, продвижение, штрафы и постоянные расходы в результат не входят.

Calltouch. Публичный пример JSON-ответа журнала показывает сессию, время начала звонка, его собственный ID, длительность и признак успешного соединения. Есть ответ с успешным вызовом, длительностью 13 секунд и order=null. В другом примере для статического пула sessionId=null. Наличие записи order=null в Calltouch само по себе ничего не говорит о наличии сделки в CRM.

Calltouch. В описании шаблона импорта сделок определены независимые dealId, requestNumber, callId и sessionId. Это справочник для сопоставления полей. Наш CSV — аналитическая проекция, с нормализованными временем и статусами.
https://www.calltouch.ru/support/ruchnoy-vvod-dannykh/

Calltouch и amoCRM. В опубликованных примерах настройки звонок или заявка могут попасть примечанием в существующую сделку. crm-activities.csv представляет разобранные ссылки на звонки из таких примечаний.
https://www.calltouch.ru/support/nastroyka-integratsii-s-amocrm-cherez-konstruktor/

В модели сайт получает номер успешно принятой формы в ответе сервера. Клик хранит ID сессии, у него нет ID будущего звонка. Для динамической телефонии условно доступна та же сессия в журнале. Совпадение сессии и окна 0–10 минут после клика — гипотеза демо, которую нужно проверить у заказчика. Связь принимается только при единственном кандидате с обеих сторон. Для звонка без сессии возможна привязка к CRM по callId, а связь с сайтом остаётся неизвестной. Один и тот же номер телефона не служит доказательством одного обращения. Время в CSV соответствует Москве (UTC+03:00), срез статусов — конец октября. По календарному срезу обращение без сделки требует проверки создания сделки позднее.

Сборка: Python 3, стандартная библиотека. Из папки кейсов выполнить python3 build.py. Файлы CSV должны воспроизводиться побайтно. Даты записей ZIP зависят от времени сборки.
